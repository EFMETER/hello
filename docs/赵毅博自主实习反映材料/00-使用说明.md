# 使用说明（先看这篇）

## 材料清单

| 文件 | 用途 |
|------|------|
| `01-情况反映.md` | **先交学校**（打印签字） |
| `02-附件-日程与费用说明.md` | 与主文一并提交；教育厅投诉时同样附上 |
| `03-教育厅投诉说明-备用.md` | 学校 3 个工作日内无书面妥善答复后再用 |

## 递交顺序

1. 把日程附件按孩子回忆填全（日期、地点、当天做什么）。
2. 打印 `01` + `02`，**学生、家长都签字**，一式两份。
3. **中秋后、十一前那 3 个工作日的第 1 天一上班**交设计学院学工办或教务办；邮件同步发出。
4. 截止日期写死（建议交件日起算第 3 个工作日 17:00 前）。对方签收或拍照留证。
5. 这 3 天内：不去电销岗；自行联系实习/就业；每天记进日程。
6. **到期无书面妥善答复** → 用 `03` + 原 `01``02` 扫描件，向河南省教育厅 / 12345 实名投诉。
7. 十一后去上海：行前发短信/邮件留联系方式（文内有示例），定性为自主联系机会，避免“失联”。

## 填写前请核对

- [ ] 学号
- [ ] 家长姓名、电话、与学生关系
- [ ] 学费/住宿费缴纳时间、缴费凭证
- [ ] 去家装侠起止日期、离职日期、休息日
- [ ] 书面答复截止日期（填具体年月日 17:00）
- [ ] 交件日期

## 对外口径（记住即可）

- 要：**自主联系实习或就业**；只按已公布最低材料交件；**不卡学分、不卡毕业证**。
- 不要写：联名；保证专业对口；接受随意加码审查；“专业无关也无所谓”（心里可以这么想，纸面不写）。
- 不签：自愿放弃自主、必须去指定单位才能毕业、实习无异议等保证书。
